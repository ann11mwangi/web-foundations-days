About QuickNotes

QuickNotes is a simple place to write down your ideas before you forget them. It keeps your notes short, quick to find, and easy to read.

How to use QuickNotes

  1. Open QuickNotes in your browser.
  2. Type your idea into a new note.
  3. Save the note so you can find it later.

Features

  • Fast note capture
  • Clean, simple layout
  • Easy to search your notes

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
